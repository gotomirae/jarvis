# 추천 종목 기준 — 6개 프로젝트 정리 · 상충 점검 · 평가 (2026-10-09, D69)

> 매수 확정 신호 아님. 모든 추천은 사람이 최종 판단한다. 수치 기준의 단일 출처는 각 저장소 설정 파일(JARVIS `config/rules.yaml`, Heimdallr `src/config/constants.py`, HermesCall `src/screener/technical_signals.py`, SnowBall `lib/rules/*`).

## 1. 프로젝트별 목적과 추천 기준

| 프로젝트 | 목적 | 무엇을 추천하나 | 핵심 기준 |
|---|---|---|---|
| **Heimdallr** (국내) | 실적이 좋아지는 국내 기업 발굴 | ⚡ 실적 속보(★○) · 📈 오늘의 추천(기술 알림, 하루 2개) · 🟢 M1·M2·M5 계산 | 실적 게이트(매출 가속·흑전) + 점수 75 · 등급 ★○. 📈 추천 = 기업 매출·영업이익 YoY 2분기 연속 개선(또는 초기 흑전) + 동종 산업 중앙값 성장 지속 + **주가 위치(A 또는 B)** + **MACD 직전·직후** + 외국인·기관 3일 연속 순매수. RSI 45 미만 상승 = 🔥 강력 표시 |
| **HermesCall** (미국 + 국내 수혜주) | 미국 실적 발표 → 수혜 기업 연결 | 🇺🇸 실적 필터 F1~F4 · 💡 국내 수혜주 기술 아이디어 · 수혜주 딥분석(LLM) · 🟢 미국 M1·M2·M5 | F1 EPS 서프라이즈 · F2 가이던스 상향 · F3 성장 가속 · F4 이익률 개선. 💡 아이디어 = 산업 센티먼트 긍정 2건+ · 실적 개선 · 발표 다음날 종가 대비 +2% 이하 · **MACD 필수 + 주가 위치(A 또는 B) 필수**, RSI 30→50 은 가산 |
| **Sage** (멘토) | 투자 고수들이 독립적으로 같은 곳을 보는가 | 멘토 합의 종목·산업·테마 | 합의 점수 = 멘토 수 × ln(1+언급) × 모멘텀, 강세/약세 분포. JARVIS 는 Sage 점수 50 이상 멘토 2명+ 합의를 N축 근거로 사용 |
| **FlyWheel** (노션) | 산업 흐름 모니터링 | 산업(L2) 신호강도 1~5 | JARVIS 는 신호강도 × 2 ≥ 8 을 N축(이야기) 근거로 사용 |
| **SnowBall** (장부) | 보유·위험 관리 — **추천 아님** | 보유 경고 · 동적 허용 비중 · 과열 | 보유 경고(주가 위치 셋 중 하나): 고점 대비 −10% · 5일선이 10일선 하향 돌파 · 5일선이 20일선 하향 돌파. 허용 비중: 글로벌 시총 20위 25% · 미국 10% · 국내 10% 상한 안에서 계수로 조정 |
| **JARVIS** (통합) | "좋은 기업"과 "지금 사기 좋은 주식"을 분리해 최종 추천 | 🎯 TOP 추천(브리핑 최대 5) · 🟢 진입 신호 | 🎯 = 매수 검토 큐(신호 계열 2개+ · 실적 증가·가속 또는 턴어라운드 등) → ⏱️ 타이밍 필수 조건 **MACD 직전·직후 + 주가 위치(A 또는 B)** + **비중 한도** + 기본 기준(⏸️ 대기 제외) + 사후 검증으로 배운 기준. 🟢 = M1∧M2∧M3∧M4∧M5 (변경 없음) |

**주가 위치 필수 조건 (모든 프로젝트 공통, 10/9 사용자 지정)**

- **A** 5일선이 10일선 상향 돌파 **직전 또는 직후(3거래일 이내)** — 옛 5·20일선을 교체. JARVIS 는 신고가 추격을 막기 위해 고점 대비 눌림(−5~−40%)을 함께 요구, Heimdallr 는 자체 "주가 미반영 구간"을 함께 요구
- **B** 52주 고점 대비 **10~20% 조정 후 10거래일 이상 횡보**(종가 폭 8% 이내)
- MACD 시그널 상향 돌파 직전·당일·직후(3거래일)는 계속 필수 (사용자 선택)
- 🟢 진입 신호의 M1 주가 조건은 그대로 (사용자 선택)

## 2. 목적에 맞게 설정돼 있는가

| 프로젝트 | 평가 |
|---|---|
| Heimdallr | ✅ 목적(실적 개선 국내 기업)과 맞다. 기술 추천의 실적 조건(2분기 연속 + 영업이익률 상승)이 JARVIS 🎯 F축(증가·가속 **또는** 턴어라운드)보다 엄격하다 — 하루 2개 알림이라 엄격한 편이 맞다 |
| HermesCall | ✅ 미국 실적 → 수혜주 연결 목적과 맞다. 다만 수혜주 딥분석(LLM)의 진입 전략에는 결정론적 주가 위치 필터가 없다 → 최종 매수 타이밍은 JARVIS 🎯 필수 조건을 거치게 두는 게 맞다(LLM 판정 금지 원칙) |
| Sage · FlyWheel | ✅ 종목 타이밍이 아니라 "주목도·흐름" 신호 — 추천 근거(N축)로만 쓰고 타이밍 조건을 넣지 않는 게 맞다 |
| SnowBall | ✅ 장부·위험 관리. 이번에 확인한 문제: **허용 비중 25% 상한이 실제로 닿지 않았다** — 기준 비중 10% 하나를 모든 등급에 써서 엔비디아 9.7% · 테슬라 8.1% · 삼성전자 6.3% · SK하이닉스 6.3% 로 계산됐다(10/9 실측). → 등급별 기준 비중(글로벌 20위 2.5배)으로 고침(D-76) |
| JARVIS | ✅ "좋은 기업 ≠ 지금 사기 좋은 주식" 분리, 사후 검증으로 기준을 자동 조정. 이번에 보유 종목의 비중 한도를 🎯 TOP 추천 자격에 추가 |

## 3. 서로 상충하는 부분

| # | 상충 | 영향 | 처리 |
|---|---|---|---|
| 1 | **사후 검증 채점**: JARVIS = 추천일 기준 **절대 수익률**(이번 변경) · HermesCall = **지수 대비 초과수익**(20거래일) | 같은 종목이 JARVIS 에선 승, HermesCall 에선 패가 될 수 있다(상승장에서 지수보다 덜 오른 경우) | JARVIS 는 절대 수익률로 채점하되 구간 비교는 "후보 전체 대비"로 해 상승장 착시를 막는다. HermesCall 은 그대로 두고 문서화 — 통일하려면 HermesCall `recommendation_feedback.py` 에 절대 기준 추가 필요(제안) |
| 2 | **눌림 정의가 제각각**: JARVIS 52주 고점 −5~−40% · Heimdallr −20% 이하(52주 또는 발표 후) · HermesCall 발표 다음날 종가 +2% 이하 · 🟢 M1 발표 후 −10% 또는 52주 −15% | 같은 종목이 프로젝트마다 "눌림/아님"이 다르다 | 이번 변경으로 **주가 위치 A·B 는 모든 추천에 공통**. 각자의 눌림 조건은 A 경로의 추격 방지용으로만 남음 — 장기적으로 하나로 통일 제안 |
| 3 | **수급 연속일**: JARVIS ⏱️ 2일 · Heimdallr 📈 3일 · 🟢 M5 2일 | 경미 | 문서화 (통일하려면 Heimdallr `TECHNICAL_INVESTOR_BUY_STREAK_DAYS` 2) |
| 4 | **RSI**: JARVIS ≤45 상승 +1 · Heimdallr <45 상승 = 🔥 표시 · HermesCall 30~50 상승 가산 | 경미(모두 필수 아님) | 그대로 |
| 5 | **보유 경고 −10% ↔ 추천 B(−10~−20% 횡보)** | 보유 종목이 같은 날 "⚠️ −10% 경고"와 "🎯 B 추천"을 동시에 받을 수 있다 | 의도된 차이: 경고 = 논지 재점검, 추천 = 신규 진입 타이밍. 보유 중이면 🎯 는 비중 한도로 걸러진다 |
| 6 | 🟢 M2 = MACD 직전·당일만 · 🎯·📈·💡 = 직후 3일 포함 | 🟢 가 더 엄격 | 의도(🟢 변경 금지) |

## 4. 기준이 적절한가 — 데이터 평가

**백테스트** (10/9, 국내 종목 248개 표본 · 최근 약 1년 · 매일 평가 58,639건, 실적·수급 필터 없이 기술 조건만, 절대 수익률)

| 조건 | 건수 | 10거래일 승률 · 중앙값 | 20거래일 승률 · 중앙값 |
|---|---:|---|---|
| 전체(아무 날) | 58,639 | 45.1% · −0.56% | 46.8% · −0.33% |
| MACD 직전·직후만 | 10,714 | 43.0% · −0.75% | 47.5% · 0.00% |
| 옛 기준: 눌림 + 5·20일선 + MACD | 1,923 | 47.8% · −0.41% | 49.7% · 0.00% |
| **새 A**: 눌림 + 5·10일선 + MACD | 4,150 | 46.3% · −0.56% | 48.8% · −0.17% |
| **새 B**: 조정 후 횡보 + MACD | 1,359 | **51.5% · +0.35%** | **57.5% · +1.33%** |
| 새 기준 전체(A 또는 B) + MACD | 4,626 | 46.3% · −0.46% | 49.6% · 0.00% |
| B 만(MACD 없이) | 6,322 | 47.8% · −0.16% | 49.0% · 0.00% |

**해석**

- **B(조정 후 횡보 + MACD)가 가장 좋다** — 20거래일 승률 57.5%, 전체보다 +10.7%p. 목표 승률 55%를 넘는 유일한 조건.
- **A(5·10일선)는 5·20일선보다 신호가 2.2배 많지만 약간 약하다** (20일 승률 48.8% vs 49.7%). 5·10일선은 빨리 돌아서는 대신 잡음이 많다.
- MACD 만으로는 우위가 없다 — 주가 위치 조건과 함께여야 의미가 있다.
- 한계: 기술 조건만 본 것(실제 🎯 는 실적·산업·수급 조건을 먼저 통과), 표본 기간이 1년이고 국내만. 실제 성과는 `/verify` 사후 검증으로 계속 확인한다.

**권고**

1. B 를 순위에서 우대 — 사후 검증 표본 30건이 쌓이면 자동으로 ⭐ 우수 기준이 되어 순위 가중된다. 그 전에 수동 우대가 필요하면 말해 주세요.
2. A 가 실제 후보에서도 약하면 사후 검증이 자동으로 TOP 추천에서 뺀다(단, 가장 좋은 경로는 빼지 않는다 — 추천이 끊겨 학습이 멈추지 않게).
3. 사후 검증 기준을 HermesCall 과 맞추기(절대 수익률 추가) · 눌림 정의 통일 — 다음 작업 후보.

## 5. 사후 검증 → 기준 자동 최적화 (D54 → D69)

1. 브리핑마다 🎯 후보 **전체**(추천 + 미추천)를 원장에 남긴다 — 선택 편향 방지
2. 매일 20:00 `outcomes_update` 가 D+5·**10**·20·40·60 을 측정, **추천일 다음 거래일 종가 기준 절대 수익률**로 채점(수익률 > 0 = 승)
3. 구간별 승률을 집계: 매수 매력 단계 · 타이밍 항목 · 점수 · **주가 위치 경로(A·B)** · **시장 국면(📈 상승장 · 📉 하락장 · ↔️ 횡보장)** 등
4. 표본 30건 이상 구간 중 20거래일 승률 55% 미만(또는 중앙값 음수)이고 후보 전체보다 2%p 이상 나쁜 구간 → **다음 브리핑부터 TOP 추천 자동 제외**, 좋은 구간 → 순위 가중
5. **시장 국면별 학습**: 지금 국면(코스피 · S&P 500 의 60일선·20일선 기울기)의 표본이 30건 이상이면 그 국면에서 배운 기준을 쓰고, 아니면 전체 기준 — 그때그때 시장 상황에 맞는 기준
6. `/verify` 에서 10거래일 · 20거래일 승률을 기준별로 나눠 보여 준다

자동 적용은 TOP 추천 선별에 한정한다. 🎯 큐 자격 · 🟢 M1~M5 · rules.yaml 임계값은 계속 "제안만"(분기 보정, D49).
